# Atendente de WhatsApp para clínicas — landing page

Página estática (HTML + Tailwind compilado + Inter local + ícones Lucide inline), publicada via GitHub Pages:
https://lsventura.github.io/bots-whatsapp-ia/

- `index.html` — página (pt-BR).
- `assets/site.css` — Tailwind v4 compilado e minificado.
- `assets/ref.js` — origem por UTM (mensagem do wa.me e assunto do e-mail) + GoatCounter sem cookie.
  Troque `GOATCOUNTER_CODE` pelo código da sua conta GoatCounter (ou deixe `""` para desligar).
- Demo de conversa: respostas reais do bot open source https://github.com/lsventura/whatsapp-ai-bot (`npm run chat`, modo base de conhecimento, clínica fictícia).
